# Sentiment-Analysis-Comparison
Comparing between 21 different machine learning and deep learning based models, along with different word embedding methods for movie review text classification task.

# Libraries used:
* Numpy
* Pandas
* scikit-learn
* tensorflow
* gensim
* nltk
* keras

  # BERT Components

- BertTokenizer
- TFBertForSequenceClassification
- bert-base-uncased
- AdamW Optimizer
